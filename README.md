# Pivní plánovač

Recepty, výpočty a varna pro domácí vaření piva: slady, chmely, rmutování, kvasnice, voda, karbonace, plánovač a varní deník.

## Instalace na iPhone / iPad

1. Otevři adresu aplikace v **Safari**.
2. Klepni na **Sdílet** → **Přidat na plochu**.
3. Spouštěj z ikony „Pivní plán“ – aplikace běží přes celou obrazovku a funguje i bez internetu.

Recepty se ukládají jen v zařízení. Mezi počítačem a telefonem je přenášej souborem `.pivo`
(Knihovna → Exportovat / Importovat recept…, např. přes AirDrop nebo iCloud Drive).

Tento repozitář je vygenerovaný skriptem `Zdrojak/build-mobile.ps1` – neupravuj ho ručně.
